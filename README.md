# GD Streaks

[![Build](https://github.com/normanrus/GD-Streaks/actions/workflows/build.yml/badge.svg)](https://github.com/normanrus/GD-Streaks/actions/workflows/build.yml)

A [Geode](https://geode-sdk.org) mod for Geometry Dash that adds a daily login streak, with a flame counter in the main menu, a streak window and a 7 day activity calendar.

The flame pill sits in the top right corner of the main menu and shows your current streak. Clicking it opens the streak window: current and best streak, the start and last activity dates, a 7 day calendar and progress to the next milestone.

## Download

Grab the `.geode` file for your game version from [Releases](https://github.com/normanrus/GD-Streaks/releases/latest) and open it with Geode.

## Features

- Daily streak: the first launch of each day counts, extra launches the same day do not.
- Missed days reset the streak, the best streak is kept.
- Main menu flame badge with the day count, hidden entirely if you prefer.
- Streak window: current streak, best streak, streak start date, last activity date, 7 day calendar with today highlighted, and progress to the next milestone.
- Notifications on streak changes, with special messages at 7, 14, 30, 50 and 100 days, and a setting to turn them off.
- Fully offline: uses the mod's save data, no servers or APIs.
- Local date based logic that survives DST changes and timezone jumps.

## Supported versions

| Geometry Dash | Geode SDK | Platforms |
| --- | --- | --- |
| 2.2081 | 5.11.2 | Windows, Android (32 and 64 bit) |
| 2.2091 | 6.0.0 | Windows, Android (32 and 64 bit) |

`mod.json` in the repository targets 2.2081. The CI workflow rewrites it for each matrix job, so both versions are built from the same sources. The code only uses APIs that exist in both SDKs.

## Project layout

```
src/
  main.cpp            MenuLayer hook: check-in, badge placement, notification
  StreakLogic.hpp     Pure streak rules and calendar math (no Geode dependency)
  StreakData.*        Persistence through Mod::get()->getSavedValue / saveData
  StreakBadge.*       Main menu flame pill
  StreakPopup.*       Streak window
  StreakNotifier.*    In-game notifications
resources/            PNG sprites (generated by scripts/generate_assets.py)
tests/                Host-only unit tests for StreakLogic.hpp
```

Streak state is persisted under these save keys: `current-streak`, `best-streak`, `start-day`, `last-day`, `last-seen` and `history` (the last 64 active days, used by the calendar).

## Building

Requirements: CMake 3.21+, Ninja, clang, the [Geode CLI](https://github.com/geode-sdk/cli) and the matching Geode SDK.

```sh
geode sdk update 5.11.2          # or 6.0.0 for GD 2.2091
geode sdk install-binaries --platform android64 --version 5.11.2
export GEODE_SDK=~/.local/share/Geode
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DGEODE_TARGET_PLATFORM=Android64
cmake --build build
```

The packaged mod ends up in `build/*.geode`. Windows builds are produced by the CI workflow on `windows-latest`; the sources do not use any platform specific code.

## Tests

The streak rules are pure standard C++ so they can be tested without the game:

```sh
c++ -std=c++20 -O2 tests/streak_logic_test.cpp -o streak_tests && ./streak_tests
```

The tests cover the first check-in, repeated launches in one day, consecutive days, resets that keep the best streak, timezone jumps in both directions, long gaps and corrupted save data.

## Regenerating the sprites

```sh
python3 -m pip install pillow
python3 scripts/generate_assets.py
```
