# v1.0.0

- Added the daily streak system with current and best streak tracking.
- Added the flame pill in the main menu top right corner, with the day count next to it.
- Added the streak window with the 7 day calendar, start and last activity dates and milestone progress.
- Added streak notifications, with special messages at 7, 14, 30, 50 and 100 days.
- Added settings to hide the counter, hide the button and disable notifications.
- Supports Geometry Dash 2.2081 (Geode 5.11.2) and 2.2091 (Geode 6.0.0) on Windows and Android.
