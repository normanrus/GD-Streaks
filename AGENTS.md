# AGENTS.md

Repository notes for future sessions working on GD Streaks, a Geode mod for Geometry Dash.

## What this is

A daily login streak mod: flame pill in the main menu, streak window with a 7 day calendar, notifications, settings. No network, no servers, no external APIs.

## Targets

- GD 2.2081 with Geode SDK 5.11.2 (mod.json in the repo points here)
- GD 2.2091 with Geode SDK 6.0.0

Both are built from the same sources; only `mod.json`'s `geode` and `gd` fields change.

## Gotchas learned the hard way

- `mod.json`'s `geode` field must be written **without** a `v` prefix (`"5.11.2"`, not `"v5.11.2"`). Geode's CMake compares a truncated version string and rejects the `v`.
- The `_spr` literal expands to a `char const*`, so `CCSprite::create("flame.png"_spr)` works directly.
- `CCNode` has no `setOpacity`; only `CCNodeRGBA` and `CCLabelBMFont` do. UI helpers that fade nodes must be templates.
- `CCLabelBMFont` is not a `CCNodeRGBA`, so do not type helper parameters as `CCNodeRGBA*`.
- Pass `nullptr` as the selected sprite of `CCMenuItemSpriteExtra` when the normal sprite is a custom node, otherwise the item's show/hide logic can hide it after a click.
- `NineSlice` insets are clamped by `factor = min(targetSize / (insetA + insetB), 1)`, so ship textures whose height already matches the target (pill: 96x36 insets 18, bar: 96x14 insets 7).
- `Popup::init(w, h)` gives `m_mainLayer` a content size of `(w, h)` anchored at the screen centre, so child coordinates are bottom-left based.
- Local Android builds need the NDK extracted with `unzip` (Python's zipfile turns the symlinked clang wrappers into broken text files). Also put the NDK `bin` on `PATH` because the `clang` wrapper execs `clang-21`.

## Build (Linux, Android)

```sh
export GEODE_SDK=~/.local/share/Geode
geode sdk update 5.11.2                     # or 6.0.0
geode sdk install-binaries --platform android64 --version 5.11.2
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DGEODE_TARGET_PLATFORM=Android64 \
  -DCMAKE_TOOLCHAIN_FILE=$NDK/build/cmake/android.toolchain.cmake \
  -DANDROID_ABI=arm64-v8a -DANDROID_STL=c++_shared -DANDROID_PLATFORM=android-23
cmake --build build
```

Use `-DGEODE_TARGET_PLATFORM=Android32 -DANDROID_ABI=armeabi-v7a` for 32 bit. Windows builds only run in CI (`windows-latest`).

## Tests

```sh
g++ -std=c++20 -O2 -Wall -Wextra tests/streak_logic_test.cpp -o /tmp/streak_tests && /tmp/streak_tests
```

`src/StreakLogic.hpp` is deliberately Geode-free so it can be tested on the host. Keep it that way.

## Layout rules of thumb

- Popup is 420x280 with hardcoded vertical constants at the top of `StreakPopup.cpp`; check for overlaps before moving anything.
- Long values are defensively fitted: the big streak number is scaled down past a `COUNT_MAX_WIDTH` cap so 3-4 digit streaks stay inside their column.
- Sprites are generated by `scripts/generate_assets.py` (Pillow) and committed, so a plain build needs no Python.
